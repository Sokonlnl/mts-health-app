# Задание

Тестовое задание для команды СберЗдоровье. Спроектировать и реализовать главный экран мобильного приложения
для мониторинга здоровья и экран одного показателя (выбрано: **давление**).
Платформа: iOS, SwiftUI. Время: 3–4 часа. Полноценное приложение не требуется.

## Что оценивают
1. **UI/UX:** качество визуала, структура экранов, основные взаимодействия.
2. **Разработка:** работающий интерактивный прототип, исходный код в Git.
3. **Harness:** как организована работа AI-агентов, правила проекта, дизайн-система, переиспользование компонентов.
4. **Контроль качества:** как агенты проверяют результат, находят и исправляют ошибки.

## Критерии приёмки
- [ ] Главный экран и экран давления реализованы по `docs/DESIGN.md`.
- [ ] Работают взаимодействия: переход между экранами, смена периода, добавление измерения, разворот вывода.
- [ ] Все цвета, шрифты и отступы берутся из `DesignSystem/`, дублей компонентов нет.
- [ ] Есть состояния loading, empty, error.
- [ ] CI собирает проект и проходит тесты; скриншоты и видео сохраняются как артефакты.
- [ ] Описан процесс: `docs/HARNESS.md`, журнал проверок `docs/QA-LOG.md`.
- [ ] Исходный код в публичном Git-репозитории.

## Что сдаём
Работающий прототип (видео и скриншоты симулятора из CI), исходный код, описание harness и контроля качества.
