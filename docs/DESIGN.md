# Дизайн-спецификация (концепция Aura, тёмная)

**Эталон дизайна: Figma.** Главный экран:
https://www.figma.com/design/wiH1VTFFlY0KXC1M6RQ8Fx/?node-id=63-25250 (узел `63:25250`, страница «Aura: Health Monitor»).
Снимок эталона: `docs/design/home-figma-63-25250.png`. История: первая версия `47:2127` (снимок `docs/design/home-figma-47-2127.png`,
ассеты `docs/design/assets/home-47-2127/`) заменена узлом `63:25250`.
Это последние наработки автора **по стилистике**: стеклянные карточки с внутренним свечением, кнопка с зелёной подсветкой,
тёмные карточки, свечение сверху с закруглённым низом, типографика. По стилю Figma главнее этого файла: при расхождении
правится код и этот документ, а не Figma. Компоновку берём из макета там, где она показана; что в макете не показано
(экран давления, шторка, состояния loading/empty/error), делаем в той же стилистике.
Холст Claude Design (https://claude.ai/artifact/HE2nEUW27e5hrek5bLxKE3) остаётся справкой по содержимому экрана давления.

Визуальное направление:
- Приложение только тёмное (`preferredColorScheme(.dark)`), фон экрана #0D0D0D.
- Верхний блок 390×540 со скруглением снизу 42 и зелёным свечением; ниже колонка карточек шириной 358.
- Цвет свечения подсказывает состояние: норма зелёный, повышенное янтарный, высокое красный, нет данных серый.
- Шрифт макета SB Sans Display, Inter и Space Grotesk; в iOS используется SF Pro (цифры карточек: SF Pro, насыщенность light).

### Анимации (`Motion`)
Все длительности и кривые только через `Motion`, числа во View запрещены. При «Уменьшить движение» (`accessibilityReduceMotion`) смена
палитры свечения идёт без анимации, переходы остаются мгновенными или кроссфейдом.
Анимация палитры дополнительно управляется окружением `isAmbientMotionEnabled` (по умолчанию включено, в snapshot-тестах выключено ради
детерминированного кадра).

| Токен | Длительность / кривая | Где |
|---|---|---|
| palette | 1,1 с easeInOut | смена палитры свечения при смене зоны |
| contentSwap | 0,7 с, кривая (0.2, 0.7, 0.2, 1) | появление значения и вывода: opacity 0→1, сдвиг вниз 8 pt, масштаб 0,98→1 |
| segment | 0,3 с easeInOut | переключатель периодов |
| sheet | 0,45 с, кривая (0.2, 0.8, 0.2, 1) | выезд шторки, подложка 0,25 с |
| breathe* | период 5 с, масштаб ±4%, яркость ±6%, фазы пятен 0 / 2,1 / 4,2 рад | «дыхание» свечения `DomeGlow`, repeatForever, у пятен разные фазы |
| heartbeatAmplitude | +12% к масштабу | сердце в большой карточке; период 60 / пульс (мок 68, без пульса 60), удар «lub-dub» и пауза (`HeartbeatRhythm`) |
| introGlow | 0,7 с easeOut | свечение разгорается из темноты при заставке |
| introItem(index:) | 0,35 с, кривая как у contentSwap, старт 0,25 с, шаг 0,08 с | вывод, карточки, советы и кнопка появляются по очереди (opacity, подъём на `introOffset` 12 pt) |
| introNanoseconds | 1,1 с | после этого заставка считается сыгранной |

Заставка и фоновое движение идут через `AmbientMotionGate`: при «Уменьшить движение» (`accessibilityReduceMotion`) и при `isAmbientMotionEnabled == false`
(snapshot-тесты) нет дыхания, сердцебиения и заставки, всё показывается сразу. Заставка играет один раз за запуск при первом показе главного
(`HomeViewModel.isIntroPending`). Launch-аргумент `-uiTestsDisableIntro` (`LaunchConfig.disablesIntro`) отключает её в UI-тестах. Порядок появления: сверху вниз. Шторка при «Уменьшить движение» выезжает кроссфейдом, «Подробнее» разворачивается без анимации. Оговорка совета: «Повышенное» «Это справочная информация. При стабильно высоких значениях обратитесь к врачу.», «Высокое» «Повторите измерение в покое. Если значение остаётся высоким, обратитесь к врачу.» (`HomeText`, выбор в `AdviceSelector`).
| standard / fast | 0,25 с / 0,2 с | разворот вывода, появление подсказки и т. п. |
| toastNanoseconds | 2 с | сколько подсказка «Скоро» остаётся на экране |

### Единицы и пустые подписи
Единицы (`AppUnit`: мм рт. ст., уд/мин, кг, ммоль/л), «Нет данных», «Нет измерений», «Измерений пока нет», «За выбранный период измерений нет.»,
прочерк, подписи «единица · статус» и «единица · пульс N» живут в `Domain/` (`AppUnit`, `AppFormat`), тексты главного экрана
(вкладки, «Советы от ГигаЧата», ГигаЧат, «Скоро будет доступно», вывод по зоне) в `HomeText`. Во View строки не дублируются.

### Контраст
Весь читаемый текст не темнее textSecondary по контрасту (не ниже 4.5:1 с фоном и с карточкой). Исключения, где допустим textTertiary:
прочерк «—» вместо значения (рядом читаемая подпись), пунктир пустого графика, выключенная кнопка «Сохранить».
Отклонения от макета ради контраста: неактивная вкладка «Анализы» белый 50% вместо 20%, строка «Медицинский помощник» textSecondary
вместо белого 40%. Текст в верхнем блоке экрана давления textPrimary (лежит на свечении).

## Логика зон давления (общая для UI и тестов)
- **Норма:** верхнее < 130 и нижнее < 85.
- **Повышенное:** верхнее 130–139 или нижнее 85–89.
- **Высокое:** верхнее ≥ 140 или нижнее ≥ 90.
Берётся худшая из двух оценок. Это справочная информация, не диагноз. Эту логику и тексты в `Domain/` не менять.
Мини-шкалы веса и глюкозы (`GaugeScale`: вес 50–100 кг, глюкоза 3–9 ммоль/л) только рисуют положение маркера, зон и оценок не дают.

Принятые решения (пользователя и при реализации):
- **Навигация оставлена.** Плавающая таблетка (Главная, Журнал, Профиль) поверх прокрутки; нижний запас `homeBottomClearance` позволяет доскроллить кнопку ГигаЧата выше неё.
- **«Подробнее» оставлена.** Разворот вывода есть в критериях приёмки (`docs/BRIEF.md`), кнопка стоит под выводом.
- **ГигаЧат и «Анализы» заглушки.** Нажатие показывает на 2 с сообщение «Скоро будет доступно» (`Toast`, `soon-toast`), VoiceOver читает его как объявление; у кнопки подсказка «Раздел пока недоступен, появится позже». Выбор вкладки не меняется.
- **Опечатки макета исправлены.** Подпись большой карточки «Пульс» → «Давление» (значение давления); значение глюкозы «122/79 мм рт. ст.» → значение глюкозы в «ммоль/л» (мок 5,4); «67 кг» у веса заменено на мок 72,4.
- **Шрифт.** SB Sans Display (Сбер, проприетарный) не встраивается, используется SF Pro с теми же кеглями и трекингом.
- **Мини-шкалы декоративны.** Полосы веса и дуга глюкозы не называют зон и норм; для VoiceOver карточка читается одной фразой («Вес 72,4 кг»).
- **Пульс** с главного экрана убран (в макете его нет); данные пульса измерения остаются в строке «мм рт. ст. · пульс N» на экране давления.
- **SF Symbols вместо SVG.** `heart.fill`, `scalemass.fill`, `drop.fill`, `sparkles`, `house.fill`, `book.fill`, `person`. SVG из `docs/design/assets/` не подключаем. У каждой иконки-кнопки есть `accessibilityLabel`.
- **Состояния.** loading: вывод скелетоном (`SkeletonHeadline`, `loading-state`), скелетоны большой и малых карточек и кнопки в той же сетке, свечение серое без анимации. empty: компактный верх (220) с серым свечением, большая карточка с «–/–» и «Нет данных», малые карточки с прочерком и «ммоль/л · измерений пока нет», `EmptyStateView` (`empty-state`). error: компактный верх и `ErrorStateView` (`error-state`, `error-state-action`).
- **Dynamic Type.** Тексты идут через `.textStyle(_:)`: рост не ограничен, кроме крупных чисел (`heroValue`, `insightTitle`, `sectionTitle`, `smallCardValue`, `metricCard*` до 1,2–1,4 раза). Карточки растут по высоте, сжатие `minimumScaleFactor` остаётся запасом по ширине. Вкладки и кнопки не меньше 44×44.
- **Идентификаторы.** Один идентификатор на контейнер: внутри элемента с `.accessibilityElement(children: .combine)` и `.ignore` идентификаторы дочерних видов не видны XCUI. `pressure-card`, `metric-card-<kind>`, `advice-card`, `gigachat-button`, `tab-wellbeing`, `tab-analyses`, `profile-button`, `soon-toast`.
- **Нижний градиент.** `BottomFade`: прозрачный сверху, 35% на 30%, 80% на 55%, сплошной на 85% высоты.
- **Контекст в моках.** Подпись контекста измерения берётся из часа измерения (`MeasurementContext.matching`: утро 5–10, вечер 17–22, иначе контекста нет).

Компоненты `DesignSystem/` главного экрана (все с `#Preview` на состояния): `DomeGlow`, `SegmentedPicker` (`.capsule`, `.tabs`), `MetricValueBlock` (значение, единица, чип; общий для большой карточки и верха экрана давления), `CornerGlow`, `IntroReveal`, `MetricCard` (`.large`, `.small`), `MetricGauge` (`.bands`, `.arc`),
`StatusPill` (`.standard`, `.tinted`), `AdviceCard`, `GlowButton`, `Toast`, `GlassSurface` (`GlassStyle`: `.material`, `.hero`, `.flat`, `.solid`, `.profile`),
`IconButton(surface:)`, `SkeletonCard` (высота и радиус параметрами), `SkeletonHeadline`, `SkeletonButton`, `StatusBarFade`, `BottomFade`.

## Обязательные состояния
Нормальное, loading, empty, error. Все в тёмной теме:
- loading: скелетоны карточек и нейтральное серое свечение без анимации.
- empty (нет измерений): серое свечение «Нет данных», прочерк «–/–» в значении, `EmptyStateView` с действием (на главном открывает давление, на экране давления шторку).
- error: сообщение в карточке и кнопка «Повторить».
Идентификаторы доступности и launch-аргументы `-uiScreen ...` для UI-тестов сохраняются.
